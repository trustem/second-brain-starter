# 🧠 Второй мозг — готовый каркас

Структура заметок, которая не разваливается через неделю, плюс настроенный ИИ-помощник,
который знает твой контекст.

**Внутри нет чужого содержимого** — только папки, вопросы к себе и шаблоны.
Наполняешь сам, своим.

---

## Что нужно сделать — 4 шага, минут 20

### Шаг 1. Установить Obsidian

Бесплатно, для личного использования навсегда.

**[obsidian.md/download](https://obsidian.md/download)** — выбери свою систему (Mac, Windows).
Установка обычная, ничего настраивать не надо.

> **Что это вообще такое.** Программа для заметок, которая хранит их обычными текстовыми
> файлами у тебя на компьютере. Не в чужом облаке, не в закрытой базе — просто папка с файлами.
> Именно поэтому с ними потом сможет работать ИИ: он умеет читать файлы.

### Шаг 2. Скачать этот каркас

Вверху этой страницы зелёная кнопка **Code** → **Download ZIP**.

Распакуй архив куда-нибудь, где не потеряешь. Например в «Документы».
Папку можно переименовать как хочешь — например «Мой мозг».

### Шаг 3. Открыть каркас в Obsidian

Запусти Obsidian → **Open folder as vault** (открыть папку как хранилище) →
выбери распакованную папку.

Слева появятся папки. Открой файл **«НАЧНИ ОТСЮДА»** — дальше он ведёт сам.

### Шаг 4. Подключить ИИ

Самый простой способ, без установки чего-либо:

1. Зайди на **[claude.ai](https://claude.ai)**, зарегистрируйся
2. Создай проект: **Projects → Create project**
3. Открой файл `CLAUDE.md` из каркаса, скопируй весь текст и вставь в поле
   **Instructions** в настройках проекта
4. Загрузи в проект те файлы, по которым хочешь разговаривать

Теперь можно писать ему как человеку — он уже знает, как с тобой разговаривать
и что делать без напоминаний.

> Есть способ удобнее — плагины, которые встраивают ИИ прямо в Obsidian и дают ему
> видеть все заметки сразу. Но начни с простого: к удобному перейдёшь, когда станет мало.

## С чего начать содержательно

**Не заполнять всё.** Одна сфера, где прямо сейчас есть вопрос без ответа.
Чаще всего это деньги или работа.

Открой файл этой сферы в папке `03 Сферы` — там готовые вопросы. Отвечай письменно,
своими словами, коряво. Красиво — потом.

**Пиши факты, а не намерения.** «Трачу примерно 300 в месяц на еду вне дома» — факт.
«Надо меньше тратить» — намерение, от него пользы ноль.

Дальше задай ИИ один вопрос по написанному. Например: «что здесь противоречит само себе?»

## Что внутри каркаса

| Папка | Для чего |
|---|---|
| `00 Входящие` | всё, что не успел разложить |
| `01 Ежедневник` | записи по дням, если захочешь |
| `02 Профиль` | о себе и своих целях — из этого ИИ понимает, с кем говорит |
| `03 Сферы` | деньги, здоровье, работа — области жизни |
| `04 Проекты` | то, у чего есть начало и конец |
| `05 База знаний` | то, что выучил и хочешь сохранить |
| `06 Архив` | закрытое, но жалко удалять |
| `_Шаблоны` | заготовки: решение, человек, источник |

Плюс `CLAUDE.md` — правила для ИИ, их потом дописываешь под себя.
И `05 База знаний/Путеводитель.md` — остальные сферы и вопросы, когда первая приживётся.

## Как понять, что работает

Не по количеству заметок. По одному признаку:

> **Ты открываешь заметки, чтобы что-то узнать, а не чтобы что-то записать.**

Если за две недели ни разу не открыл ради ответа — сфера выбрана не та.
Это не провал, а информация. Поменяй сферу.

## Частые вопросы

**Это платно?** Obsidian бесплатен. У Claude есть бесплатный уровень, его хватает
на начало.

**Мои заметки куда-то уходят?** Файлы лежат у тебя на компьютере. В ИИ попадает
только то, что ты сам загрузишь в проект.

**Я не технический человек.** Здесь ничего технического и нет: установить программу,
распаковать папку, скопировать текст в поле.

**Сколько это займёт времени?** Первая настройка — двадцать минут. Дальше по десять
минут в день, когда есть что записать. Заполнять всё сразу не надо и не получится.
